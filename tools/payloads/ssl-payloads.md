# SSL/TLS 证书变异策略

> 用于 C 类测试。集成自 Frankencert 方法论。

---

## 证书字段变异

### 有效期变异
| 变异 | 方法 |
|------|------|
| 已过期 | 设置 `notAfter` 为过去时间 |
| 未生效 | 设置 `notBefore` 为未来时间 |
| 极端有效期 | `notBefore=1970-01-01`, `notAfter=2099-12-31` |
| 有效期=0 | `notBefore == notAfter` |
| 负有效期 | `notAfter < notBefore` |

### 域名变异
| 变异 | 方法 |
|------|------|
| 域名不匹配 | CN 与访问域名不同 |
| 通配符滥用 | `*.*.example.com` |
| 空 CN | CN="" |
| 超长 CN | CN=1000+ 字符 |
| Unicode CN | 国际化域名 (IDN) 含混淆字符 |
| IP 地址 | CN=127.0.0.1, CN=0.0.0.0 |

### 扩展变异
| 变异 | 方法 |
|------|------|
| 未知关键扩展 | 添加未注册的扩展 OID，标记为 critical |
| 重复扩展 | 添加两个相同的 SAN 扩展 |
| 冲突扩展 | SAN 与 CN 不一致 |
| 缺失必需扩展 | 移除 Authority Key Identifier |
| BasicConstraints | 标记为非 CA 但签发子证书 |

### 签名变异
| 变异 | 方法 |
|------|------|
| 自签名 | 使用自己的公钥签名 |
| 未知 CA | 用不在信任链中的 CA 签名 |
| 弱签名算法 | MD5、SHA-1 |
| 签名不符 | 修改证书内容但不更新签名 |
| 空签名 | signatureAlgorithm 为空 |

### 链式证书变异
| 变异 | 方法 |
|------|------|
| 中间证书缺失 | 不提供中间 CA 证书 |
| 证书链乱序 | 以非标准顺序提供链 |
| 跨签发 | 不同的中间 CA 签发 |
| 循环链 | CA 证书指向自身 |
| 过长的链 | 10+ 层深度的证书链 |

## 变异生成策略（Frankencert 方法）

```
种子证书收集
    │
    ▼
随机选择 N 个种子证书
    │
    ▼
对每个字段独立随机变异：
├── 字段值变异 (60% 概率)
├── 字段删除 (20% 概率)
├── 字段重复 (10% 概率)
└── 跨证书字段拼接 (10% 概率)
    │
    ▼
生成 Frankencert → 签名 → 输出
```

## 差分测试矩阵

| 被测库 | 比较对象 |
|--------|---------|
| OpenSSL | GnuTLS, NSS, LibreSSL |
| BoringSSL | OpenSSL, LibreSSL |
| 自定义实现 | OpenSSL |

对每个 Frankencert 比较：
1. 证书验证结果（PASS/FAIL）
2. 错误码/错误信息
3. 是否存在结果不一致

---

## 使用说明

1. 先收集一批真实 SSL 证书作为种子
2. 使用 Frankencert 工具 (`franken_generate.py`) 或手动 OpenSSL 命令生成
3. **CA 证书仅在测试期间可信**，测试后立即从信任链中移除
4. 对每个变异证书记录：库名称、版本、验证结果、错误信息
