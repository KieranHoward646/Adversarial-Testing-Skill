## 2. 测试允许的操作

| 操作 | 允许？ | 备注 |
|------|:------:|------|
| 发送 HTTP 请求 | ✅ | 仅限测试端点 |
| 测试数据库写入 | ✅ | 仅限 test_db |
| 修改测试配置文件 | ✅ | 需备份 |
| 并发请求 | ✅ | 最多 N 并发 |
| 大载荷请求 | ✅ | 上限 N MB |

---

## 3. 绝对禁止的操作

| 操作 | 原因 |
|------|------|
| DROP TABLE / DATABASE | 不可逆破坏 |
| TRUNCATE | 不可逆破坏 |
| 无条件 DELETE / UPDATE | 数据丢失风险 |
| 修改生产配置文件 | 服务中断风险 |
| 向外部发送真实请求 | 法律/合规风险 |
| 端口扫描 / DDoS 模拟 | 网络滥用 |
| 修改系统环境变量 | 系统不稳定 |
| 安装/卸载系统软件包 | 环境污染 |

---

## 4. 停止规则

如果发现以下情况，**立即停止所有测试**并通知负责人：

- [ ] SQL 注入确认可行（参数化查询缺失）
- [ ] 越权访问确认可行（可访问其他用户数据）
- [ ] 远程代码执行（RCE）确认可行
- [ ] 数据泄露（PII / API 密钥 / 密码泄露）
- [ ] 服务崩溃或拒绝服务
- [ ] 任何非预期的生产数据修改

---

## 5. 测试后清理

- [ ] 删除所有测试过程中创建的数据
- [ ] 恢复被修改的配置文件
- [ ] 确认系统恢复正常状态
- [ ] 归档测试结果
